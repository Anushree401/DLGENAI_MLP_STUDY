Week 1 · Neural networks: the essential theory

Neuron, layers, and the forward pass

A neuron forms a weighted sum plus a bias, then applies an activation: z=Wx+b, a=φ(z). In a batch with examples as rows, PyTorch Linear uses Z=XWᵀ+b; weight shape is [out,in]. The bias shifts the threshold. Multiple affine layers without a nonlinear activation still combine into one affine layer, so hidden nonlinear activations give networks richer boundaries.

z = Σj=1dwjxj + b    ;    a = φ(z)

Activation landmarks: sigmoid σ(z)=1/(1+e−z), with σ′=σ(1−σ) and maximum derivative 0.25 at z=0; ReLU max(0,z); softmax turns class scores into probabilities that sum to 1.

Worked forward-pass numerical (paper style)

Use x=[1,−1], W₁=[[1,−1],[−0.5,1]], b₁=[0,−0.5], ReLU hidden layer, W₂=[1,0.5], b₂=0, linear output.

  1. z₁=W₁x+b₁=[2,−2].
  2. h=ReLU(z₁)=[2,0].
  3. ŷ=W₂h+b₂=2.
  4. For target y=1.5, squared error (ŷ−y)²=(2−1.5)²=0.25.
Do not swap layer order: apply hidden activation before using the next layer. A changed activation changes every later value.

Loss, metrics, and learning

RegressionReal value(s)MSE or MAEMSE squares errors; large errors matter more.

Gradient descent steps opposite the gradient: θ←θ−η∇L. Backpropagation applies the chain rule backward through the computation. A metric such as accuracy reports performance; it is not necessarily the differentiable objective used for training.

Gradient-update numerical

For ŷ=wx, L=½(ŷ−y)², x=2,y=1,w=0.2: ŷ=0.4, error −0.6, L=0.18, and dL/dw=(ŷ−y)x=−1.2. At learning rate 0.1, w_new=0.2−0.1(−1.2)=0.32.

Week 2 · Training loop and optimization

Data roles and counting

Train updates weights; validation helps choose settings and stopping time; test is a final held-out check. One epoch is one pass through the training set. With N=1,000 and batch size 64, there are ceil(1000/64)=16 batches/updates per epoch if the last partial batch is kept.

For Dense with 3 inputs and 4 outputs: weights 3×4=12, biases 4, total 16 parameters. Batch size does not multiply parameter count.

Optimizer quick comparison

  • SGD: subtract learning-rate × current gradient.
  • Momentum: smooths steps by remembering recent gradient direction.
  • RMSprop: rescales steps using a running estimate of squared gradient size.
  • Adam: combines running gradient mean and squared-gradient scale.

For w=0.5, gradient g=0.2, and η=0.1, one plain SGD step is w_new=0.5−0.1(0.2)=0.48. Optimizer details such as momentum, adaptive scaling, and weight decay change the update rule.

Small Keras pattern

model = keras.Sequential([
    keras.layers.Dense(16, activation="relu", input_shape=(4,)),
    keras.layers.Dense(3)  # 3 raw class logits
])
model.compile(optimizer="adam",
              loss=keras.losses.SparseCategoricalCrossentropy(from_logits=True),
              metrics=["accuracy"])
model.fit(x_train, y_train, validation_data=(x_val, y_val), epochs=20)
Training-code order: zero old gradients → forward → compute loss → backward → optimizer step. Defining a transform does not apply it; call it in the dataset pipeline. Validation must not update weights.

Week 3 · CNN theory and shape numericals

What convolution contributes

A small learned filter slides over local image patches and is reused at every position. This gives local connectivity and weight sharing. Each output channel is one learned feature detector; channels after early layers are feature types, not necessarily RGB colors.

Hout = ⌊(H + 2P − D(K−1) − 1)/S⌋ + 1    ;    parameters = KhKwCinCout + Cout

For 32×32, 3×3, stride 1, padding 1: output remains 32×32. For 28×28 with 5×5 valid, stride 1: 24×24. A 3×3 conv with 3 input channels and 16 filters has 3×3×3×16+16=448 parameters.

Pooling, receptive field, and efficient heads

2×2 max pooling with stride 2 halves each spatial dimension: 32×32 → 16×16. Two stacked 3×3 stride-1 convolutions have receptive field 5×5 (one 3×3 view, then one extra border of context). A 1×1 convolution mixes channel values at each pixel without mixing neighboring pixels.

Flatten then Dense can create many parameters: 7×7×64 → 3,136 features; a 10-class dense head uses 31,370 parameters including bias. Global average pooling makes 64 values; its 10-class head uses only 650 parameters.

Shape checklist: PyTorch image layout is NCHW = [batch, channels, height, width]. After pooling or convolution, recompute H,W; after flatten, compute all remaining elements per example. Concatenation changes one specified axis and requires other axes to match.

Week 4 · CNN image-classification practice

Common inputs: MNIST [B,1,28,28]; CIFAR-10 [B,3,32,32]. ToTensor changes image layout to channels-first and usually scales byte pixels to [0,1]. Channel normalization applies (x−mean)/std with one training-set mean/std per channel.

During training: model.train(), forward, loss, backward, step. For evaluation: model.eval() and no gradient tracking. Dropout is active in training and off in evaluation; batch normalization updates running statistics only during training.

for images, labels in train_loader:
    images, labels = images.to(device), labels.to(device)
    optimizer.zero_grad(set_to_none=True)
    logits = model(images)               # [B, classes], no softmax
    loss = criterion(logits, labels)
    loss.backward()
    optimizer.step()
Fast traps: do not apply softmax before CrossEntropyLoss; do not average batch accuracies equally if batch sizes differ; fit normalization statistics on training data only; augmentation must preserve the label.

Week 5 · RNNs and LSTMs

Recurrent state and BPTT

An RNN reads one item at a time and carries a hidden-state summary: ht=φ(Wxhxt+Whhht−1+b). The same weights are reused at each time step. Backpropagation through time unrolls that repeated calculation and sends gradients backward; repeated multiplication can cause vanishing or exploding gradients.

LSTM memory and gates

An LSTM maintains hidden state ht and cell state ct. Forget gate keeps old memory, input gate writes selected candidate content, and output gate controls what is revealed:

ft=σ(…)  it=σ(…)  gt=tanh(…)
ct=ft⊙ct−1 + it⊙gt
ot=σ(…)  ht=ot⊙tanh(ct)

Scalar update: if ct−1=0.5, f=0.8, i=0.2, g=0.5, o=0.7, then ct=0.8(0.5)+0.2(0.5)=0.5; ht=0.7 tanh(0.5)≈0.323.

For a basic single-layer unidirectional RNN, parameters are roughly H(D+H+1). For PyTorch LSTM with four gates and two bias vectors, 4H(D+H+2). Bidirectionality doubles directional recurrent weights/outputs. Check exact API shapes: with batch_first=True, input is [B,T,D], output is [B,T,H×directions].

Quick code-tracing patterns (Weeks 1–5)

Autograd is not an update

loss.backward() fills gradients. Only optimizer.step() changes parameters.

Zero gradients once per update

Calling zero_grad() after backward can erase the current learning signal; PyTorch gradients otherwise accumulate.

Shapes before arithmetic

Write tensor dimensions at every layer. A shape mismatch is often the hidden error in code-output questions.

Training/evaluation differs

Call train() and eval() explicitly; evaluation does not call backward or optimizer step.

Compact end-to-end PyTorch classifier

import torch
from torch import nn

model = nn.Sequential(nn.Linear(2, 8), nn.ReLU(), nn.Linear(8, 1))
loss_fn = nn.BCEWithLogitsLoss()  # model returns logits
optimizer = torch.optim.Adam(model.parameters(), lr=1e-2)

for x, y in train_loader:           # x: [B,2], y: [B,1]
    optimizer.zero_grad(set_to_none=True)
    logits = model(x)                # [B,1]
    loss = loss_fn(logits, y.float())
    loss.backward()                  # calculate gradients
    optimizer.step()                 # update weights

model.eval()
with torch.no_grad():
    probabilities = torch.sigmoid(model(x_test))

Final recall: neuron = weighted sum + bias + activation; batch Dense = XWᵀ+b; CNN shares filters spatially; recurrent models reuse weights over time; gradients tell direction, optimizer performs update.
