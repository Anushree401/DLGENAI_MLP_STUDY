00 · Start here: deep learning without scary words

Welcome! This series begins from zero. A neural network is a calculator with adjustable numbers. We show it examples, measure how wrong it is, and use that error to adjust the numbers.

How to use: open the notebook in Jupyter, run each code cell in order with Shift + Enter, and read the explanation right after it. Code cells in this series use small toy data and do not need a GPU or dataset download. PyTorch must be installed in the Python environment used by Jupyter.

The picture: example → prediction → error → learning

  • Input: the clues we give the model (for example, pixel brightness values).
  • Weight: a number that decides how much a clue matters.
  • Bias: a learned offset added to a weighted sum.
  • Neuron: computes a weighted sum plus bias, then applies a function.
  • Layer: a group of neurons.
  • Prediction: what the model says.
  • Loss: a number describing how wrong the prediction is.
  • Gradient: a direction and size describing how changing a parameter changes the loss.
  • Optimizer: a rule that uses gradients to update weights.

Training repeats: predict → measure loss → calculate gradients → update weights.

0302 · Neurons, activations, and forward passesReady

02 · Neurons, activations, and forward passes

A neuron is a small recipe: multiply inputs by weights, add the results and a bias, then apply an activation. We will calculate each step by hand and with PyTorch.

Weighted sum and activation

For inputs x₁,…,xₙ, weights w₁,…,wₙ, and bias b: z = Σᵢ xᵢwᵢ + b. The value z is the pre-activation. The neuron output is a=f(z). The activation function lets a network represent curved/nonlinear relationships; without nonlinear activations, many stacked linear layers collapse to one linear transformation.

Click Run to execute this cell.

Three activations to know

  • ReLU: max(0,z). Negative inputs become zero; positive inputs pass through.
  • Sigmoid: 1/(1+exp(−z)), values between 0 and 1. sigmoid(0)=0.5; its derivative is s(1−s) and peaks at 0.25 when s=0.5.
  • Tanh: values between −1 and 1; tanh(0)=0.

Sigmoid is often used to express a binary probability; ReLU is common in hidden layers. An output activation/loss pairing must match the task.

Click Run to execute this cell.

McCulloch–Pitts threshold neuron and XOR

A simple threshold neuron outputs 1 if the weighted sum reaches a threshold, otherwise 0. With two positive inputs, it can represent AND by firing only when both inputs are 1. But a single straight-line boundary cannot separate the XOR pattern (opposite corners positive) from the other two corners. A hidden layer can combine multiple boundaries to solve XOR.

Click Run to execute this cell.

A multilayer forward pass

A layer is often written z = W x + b, then h = activation(z). The output layer uses the previous layer’s activations as input. In PyTorch nn.Linear(in_features, out_features) stores weights with shape (out_features, in_features) and a bias with shape (out_features,). Matrix multiplication is why dimensions must match.

Universal Approximation Theorem (UAT)

At a high level, the UAT says a sufficiently wide neural network with a suitable nonlinear activation can approximate a broad class of continuous functions on a bounded region to arbitrary accuracy. It does not say that gradient descent will find the desired weights, that a small network suffices, or that the network generalizes from limited data.

0403 · Loss, autograd, and backpropagationReady

03 · Loss, autograd, and backpropagation

A loss is the model’s “how wrong am I?” score. Backpropagation figures out how much each parameter contributed to that score. PyTorch’s autograd engine applies the chain rule for us.

Loss functions: squared error and cross entropy

For one regression example, squared error is (prediction − target)²; for a batch, mean squared error averages those squares. Binary cross-entropy measures the mismatch between a binary target and a predicted probability. Multiclass cross-entropy compares class logits with an integer class label. With CrossEntropyLoss, provide raw logits (do not add a softmax yourself) and torch.long class-index targets.

A tiny derivative by hand

Suppose y_hat = w*x and loss L=(y_hat−y)². Chain rule gives dL/dw = 2(y_hat−y)*x. If x=3, w=2, target=4, then y_hat=6, error=2 and gradient=12. A positive gradient means increasing w increases loss here; gradient descent subtracts a small multiple of it.

Computation graph and backward()

When a tensor operation uses a parameter with requires_grad=True, PyTorch records how the result was made. Calling .backward() on a scalar loss walks backward through that graph and places derivatives in leaf tensors’ .grad fields. A tensor is a leaf when it was created directly rather than produced by an operation. Intermediate gradients are normally not retained unless requested.

Backpropagate through a tiny network

For h=ReLU(W₁x+b₁) and y_hat=W₂h+b₂, gradients flow from the loss through W₂, then the activation, then W₁. When the question asks for a hidden-activation gradient, multiply the output gradient by the relevant output weight(s), summing contributions from each output. Why clear gradients?

PyTorch adds new gradients into .grad; it does not replace old gradients automatically. That is useful when intentionally accumulating gradients across mini-batches, but ordinary training should clear gradients before each update. The next notebook shows the standard order.

0504 · Build a model and write a correct training loopReady

04 · Build a model and write a correct training loop

This is the practical heart of training in PyTorch. We define a model, choose a loss and optimizer, then repeat the correct five-step loop.

nn.Module and registered parameters

Subclass nn.Module; create layers in __init__; implement forward. Parameters inside registered layers (or values wrapped in nn.Parameter) appear in model.parameters(). A plain Tensor—even one with requires_grad=True—can receive gradients but is not automatically registered for the optimizer to update.

Python · code cell 1 
Click Run to execute this cell.

A correct training-loop order

For each mini-batch:

  1. optimizer.zero_grad() clears gradients from the previous update.
  2. prediction = model(inputs) runs the forward pass.
  3. loss = loss_fn(prediction, target) measures error.
  4. loss.backward() calculates gradients.
  5. optimizer.step() changes registered parameters.

If zero_grad() is missing, gradients accumulate. If backward() is missing, gradients are not computed. If step() is missing, parameters are not updated.

Train mode, evaluation mode, and no-grad are different

model.train() sets training behavior for modules such as Dropout and BatchNorm. model.eval() switches those modules to evaluation behavior. torch.no_grad() turns off gradient recording in a code region to save memory during evaluation. eval() does not turn off autograd, and no_grad() does not itself switch Dropout or BatchNorm. Use both when evaluating.

05 · Examples, batches, DataLoaders, and transforms

A dataset knows how to return one example. A DataLoader gathers examples into mini-batches and can shuffle them. A transform changes one example, for example turning a picture into a tensor and normalizing its pixel values.

Image shape and pixel scale

A grayscale image may begin as a height-by-width array (H,W). A CNN expects channels too, commonly (C,H,W) for one image or (N,C,H,W) for a batch. Pixel values stored as integers 0…255 are often converted to floating-point values 0…1. Normalization then subtracts a chosen mean and divides by a chosen standard deviation per channel.

0706 · CNNs: convolution, shape, padding, and parameter countsReady

06 · CNNs: convolution, shape, padding, and parameter counts

A convolutional neural network looks for local patterns in images. A small learned filter slides across an image; the same filter weights are reused at many positions. This sharing is why convolution can use far fewer parameters than a fully connected layer on pixels.

Image and filter dimensions

Use the common PyTorch batch shape (N,C,H,W): batch size, input channels, height, width. A Conv2d filter has shape (C_out,C_in,K_h,K_w). Each output channel comes from one learned filter that spans all input channels. nn.Conv2d(in_channels, out_channels, kernel_size, stride, padding) specifies the layer.

Python · code cell 1 
Click Run to execute this cell.

Output size formula

For one spatial dimension: output = floor((input + 2*padding − kernel_size)/stride) + 1. Calculate height and width separately. With input 10, kernel 3, padding 0, stride 1: output is (10−3)/1+1 = 8. Padding 1 makes it 10. Stride 2 reduces the number of positions because the filter jumps two pixels.

Python · code cell 2 
Click Run to execute this cell.

SAME and VALID padding

Valid commonly means no padding (padding=0): the filter only fits where it fully overlaps the input, so spatial size shrinks. Same means output spatial dimensions match input for stride 1. For an odd kernel K, symmetric padding per side is (K−1)/2: K=3 → 1 pixel; K=5 → 2 pixels. For even kernels or strides greater than 1, padding can be asymmetric and the exact framework definition matters.

Convolution parameter counts

For one Conv2d: weights = K_h × K_w × C_in × C_out; if bias is enabled, add C_out. For a Linear layer: weights=in_features × out_features; add out_features biases if enabled. Pooling, ReLU, sigmoid, flatten, and dropout have zero learned parameters.

Click Run to execute this cell.

Pooling, 1×1 convolution, receptive field

A 2×2 max-pool with stride 2 halves height/width when divisible by 2; it has no trainable weights. A 1×1 convolution changes channels but (with stride 1 and no spatial padding need) preserves height/width. Receptive field is the input region that can affect one output. For n stride-1 convolutions of kernel K, RF = 1+n(K−1); three 3×3 layers give 7×7.

Flatten vs Global Average Pooling (GAP)

Flatten turns a (C,H,W) feature map into C×H×W numbers. GAP averages each channel over its H×W positions, leaving C numbers. With 7×7×512 features and 10 output classes, flatten + dense layer needs 25088×10+10=250,890 parameters; GAP + dense needs 512×10+10=5,130. Inception branches with matching H,W concatenate along the channel axis, so output channels are the sum of branch channels.

0807 · Dropout, BatchNorm, and image-model trainingReady

07 · Dropout, BatchNorm, and image-model training

Some layers behave differently while learning and while making final predictions. The model must be told whether it is training or evaluating.

Dropout

During training, Dropout randomly sets input elements to zero with probability p. Remaining values are scaled so their expected size stays comparable. This discourages reliance on one exact pathway. During evaluation, Dropout is the identity: no units are randomly removed. The mask is random each training call, not a fixed sequence of neurons.

BatchNorm

Batch normalization normalizes activations using batch statistics during training, then maintains running estimates for evaluation. BatchNorm2d(C) on image tensors normalizes per channel. It has two learnable values per channel (scale γ and shift β), so 2C learnable parameters, plus running-statistic buffers that are not trainable parameters.

0908 · Optimization: SGD, Adam, and gradient problemsReady

08 · Optimization: SGD, Adam, and gradient problems

An optimizer is the rule that nudges the model’s weights to reduce its loss. This notebook builds the intuition behind gradient descent, mini-batches, momentum, Adam, vanishing gradients, and clipping.

Gradient descent

A gradient points toward the direction of fastest increase in loss. To reduce loss, update parameter θ as θ ← θ − learning_rate × gradient. The learning rate controls step size. Too small: slow learning. Too large: jump past a good solution or become unstable. In PyTorch, an optimizer automates the parameter updates after loss.backward().

Python · code cell 1 
Click Run to execute this cell.

Batch, stochastic, and mini-batch updates

  • Batch gradient descent: use the whole training set for each update; stable but may be slow.
  • Stochastic gradient descent: use one example per update; noisy, frequent updates.
  • Mini-batch SGD: use a small group per update; common compromise in deep learning.

One pass over all training examples is an epoch. A mini-batch is not the same as an epoch.

SGD, momentum, RMSprop, Adam

SGD uses the current gradient. Momentum adds a running direction to smooth updates. RMSprop scales learning rates using recent squared gradients. Adam combines first-moment (momentum-like) and second-moment (adaptive-scale) estimates with bias correction. Adam is a common starting point, but it is not guaranteed to be best. Weight decay is a separate regularization choice; AdamW decouples it from Adam’s adaptive update.

Click Run to execute this cell.

Vanishing and exploding gradients

Backpropagation multiplies derivatives across layers/time steps. If many factors are small, gradients can shrink toward zero (vanish); if factors are large, they can grow explosively (explode). Sigmoid/tanh saturation can contribute to vanishing gradients. ReLU variants and residual connections help in some architectures; gradient clipping limits very large gradients, especially in recurrent networks.

1009 · Generative models and GANsReady

09 · Generative models and GANs

A discriminative model answers “which label fits this input?” A generative model learns patterns in data so it can create new examples. A GAN has two networks that compete: a generator creates fakes; a discriminator judges real versus fake.

Generator, discriminator, latent vector

The generator receives a random latent vector z (noise) and maps it to a synthetic sample. The discriminator receives a sample and predicts whether it came from real data. During training, the discriminator tries to classify correctly, while the generator tries to fool it. This game can be unstable; the generator may collapse to producing only a few kinds of output (mode collapse).

Minimax idea

The original GAN objective is min_G max_D E[log D(x)] + E[log(1−D(G(z)))]. D wants D(real) near 1 and D(fake) near 0. G wants D(fake) near 1. In practice a non-saturating generator loss −E[log D(G(z))] often gives stronger gradients early. At an ideal equilibrium, D cannot distinguish real and generated samples and outputs about 0.5.

Click Run to execute this cell.

One tiny alternating training step

We use 1D toy “real” samples, not images. BCEWithLogitsLoss combines sigmoid and binary cross-entropy stably. First update D using real labels 1 and fake labels 0; detach fake samples so this update does not train G. Then update G with the discriminator’s fake predictions labeled as real. This demonstrates the mechanics; it is not a state-of-the-art GAN recipe.

GAN vs VAE, at a high level

A Variational Autoencoder learns a structured latent distribution and optimizes a reconstruction-plus-regularization objective (ELBO). GANs use an adversarial game. VAEs often provide a more organized latent space and stable likelihood-based training; GANs can produce sharp samples but can be harder to train and may omit modes. These are tendencies, not absolute laws.

1110 · Sequences: RNN, LSTM, and GRUReady

10 · Sequences: RNN, LSTM, and GRU

A sequence is an ordered list, such as words in a sentence or daily temperatures. A recurrent network reads one step at a time and carries a hidden state—a small memory—forward.

Vanilla RNN equations and tensor shapes

At time t: h_t = tanh(W_xh x_t + W_hh h_(t−1) + b_h). The output may be y_t = W_hy h_t + b_y. The previous hidden state carries information from earlier steps. In PyTorch, a batch-first sequence has shape (batch, sequence_length, input_features) when batch_first=True. The initial hidden state can be zero or learned.

Click Run to execute this cell.

Why long sequences are hard

Backpropagation through time (BPTT) unrolls the recurrence across steps and applies the chain rule backward. Repeated multiplication by recurrent weights/derivatives can make gradients vanish or explode. Truncated BPTT limits backward propagation to a chosen number of steps, reducing memory/computation but limiting long-range credit assignment.

LSTM: a controlled memory cell

An LSTM adds a cell state c and gates. The forget gate chooses how much old memory to keep; the input gate chooses how much candidate information to write; the output gate chooses what to reveal. Sigmoid gates range 0…1. The additive cell-state update helps gradients travel across many steps. Typical formulas are f=σ(...), i=σ(...), ĉ=tanh(...), c=f⊙c_prev+i⊙ĉ, o=σ(...), h=o⊙tanh(c). ⊙ means element-wise multiplication.

GRU: fewer gates

A GRU combines memory into the hidden state and uses reset/update gates. It has fewer gates/parameters than an LSTM and can perform comparably, but no single recurrent unit is best for every task. Compare using validation data.

Encoder-decoder and bidirectional ideas

An encoder converts an input sequence into hidden representations; a decoder generates an output sequence, useful in translation. A bidirectional RNN reads left-to-right and right-to-left, then combines both directions. 11 · Attention, Transformers, and language models

Attention lets each token choose which other tokens to use as context. Transformers build heavily on attention and feed-forward layers, avoiding the strictly step-by-step recurrence of a vanilla RNN.

Query, Key, Value

Each token is projected into a query (what it seeks), key (what it can match on), and value (the content to pass along). Similarity between queries and keys becomes an attention weight; a weighted sum of values creates the attended representation.

Scaled dot-product attention

Attention(Q,K,V)=softmax(QKᵀ/√d_k)V. The dot product measures match strength. Dividing by √d_k keeps large dimensions from producing overly large logits that make softmax saturate. Softmax weights are nonnegative and sum to 1 across the attended positions.

Self-attention, cross-attention, and position

  • Self-attention: Q, K, V come from the same sequence.
  • Cross-attention: queries come from a decoder sequence; keys/values come from encoder outputs.
  • Self-attention alone does not know token order. Positional encodings or learned position embeddings add this information.
  • Causal masking prevents a next-token model from looking at future tokens.

Transformer blocks

An encoder layer typically has multi-head self-attention then a position-wise feed-forward network, with residual connections and layer normalization. A decoder adds masked self-attention and often cross-attention. Multi-head attention runs several attention patterns in parallel and concatenates/projects their outputs.

A language model predicts token sequences. GPT-style decoder-only models use causal attention and predict the next token. BERT-style encoder models use bidirectional context and commonly train by predicting masked tokens. A token is a chunk of text, not always one word. A large language model is a transformer-based model trained on a very large text corpus; prompting and fine-tuning are different ways to guide behavior.

12 · Diffusion models: add noise, learn to remove it

A diffusion model learns to turn noise into a sample. During training we gradually corrupt a real sample with known noise. The neural network learns to predict the noise. During generation we begin with random noise and repeatedly denoise.

Forward noising process

A common DDPM formula samples x_t = √(ᾱ_t)x_0 + √(1−ᾱ_t)ε, where x₀ is the original data, ε is standard Gaussian noise, and ᾱ_t decreases as the noise level grows. At late t, x_t is mostly noise. A schedule defines how quickly the signal is removed.

Training objective

A neural network εθ(x_t,t) receives the noisy sample and time/noise level. A common simplified DDPM objective is the mean squared difference between true added noise ε and predicted noise εθ. The network is not directly asked to paint the clean sample in one step; it learns a denoising direction for many steps.

Reverse sampling, DDIM, and guidance

At inference, start with x_T sampled from a standard Gaussian and apply a learned reverse update from T down to 0. DDPM sampling is stochastic. DDIM provides a family of updates that can be deterministic and often use fewer steps. Classifier-free guidance combines conditional and unconditional noise predictions: ε_guided=ε_uncond+w(ε_cond−ε_uncond). Larger w usually strengthens conditioning but can reduce diversity or quality if pushed too far.

Latent diffusion

Images contain many pixels. Latent diffusion first encodes an image into a smaller latent representation, performs diffusion there, then decodes back to pixels. This can reduce computation while preserving useful structure. Stable Diffusion is a well-known latent diffusion family, but specific model designs vary.

PyTorch documentation reference · practical details

This appendix paraphrases the API behavior most relevant to the notebook topics. Official docs are linked for full signatures, version-specific behavior, and additional caveats.

Tensors, shapes, and devices

A torch.Tensor has a shape, dtype, device, and layout. Operations generally require compatible shapes, dtypes, and devices. numel() is the total number of elements; element_size() is the bytes per element. stack requires equal shapes and adds a new dimension. cat joins along an existing dimension and requires all other dimensions to match. squeeze(dim) removes that axis only when its size is 1; no-argument squeeze() removes every size-1 axis. unsqueeze(dim) inserts a length-1 axis. reshape may return a view or copy; view requires compatible strides/contiguous layout. A tensor created from NumPy with from_numpy shares CPU storage when compatible; torch.tensor copies.

For convolutional images, PyTorch commonly uses (N,C,H,W). nn.Linear(in_features,out_features) accepts any input whose final dimension is in_features, replaces that final dimension with out_features, and stores weight shape (out_features,in_features) plus optional bias shape (out_features,).

Modules, parameters, autograd, and training

nn.Module registers submodules and parameters assigned as attributes. nn.Parameter is a Tensor subclass that, when assigned as a module attribute, is automatically registered and returned by parameters(). A plain tensor with requires_grad=True can receive a gradient but is not automatically included in an optimizer's parameter list.

Autograd records operations on tensors requiring gradients and computes derivatives through the graph. .backward() accumulates gradients into leaf tensors' .grad; it does not clear them. optimizer.zero_grad() clears them. The standard order is clear → forward → loss → backward → update. torch.no_grad() and torch.inference_mode() disable autograd recording for their contexts. module.eval() changes modules with training-specific behavior (e.g. Dropout/BatchNorm); it does not disable autograd. These controls are independent.

A state dictionary stores parameters and persistent buffers. Saving/loading state_dict() is the preferred pattern for restoring learned weights into an instantiated model. Model architecture must match the keys/shapes in the state dictionary.

Loss input contracts

  • MSELoss: inputs/targets have compatible shapes; by default, squared elementwise errors are averaged (reduction="mean").
  • BCELoss: expects probabilities in [0,1]. BCEWithLogitsLoss expects raw logits and combines sigmoid with BCE more stably.
  • CrossEntropyLoss: expects unnormalized class logits (commonly (N,C) or (N,C,H,W)) and class-index targets of dtype long with matching batch/spatial dimensions; it internally applies log-softmax and negative log likelihood. Do not apply softmax before it in the usual class-index case.

Data API and image transforms

A Dataset implements __len__ and __getitem__; a DataLoader batches samples, optionally shuffles, and can use workers/pinning. Dataset transforms are commonly called from __getitem__; merely defining a transform object does not apply it. TorchVision ToTensor converts common PIL/NumPy image inputs to channel-first floating tensors and scales uint8 [0,255] pixels to [0,1]. Normalize(mean,std) applies channel-wise (x−mean)/std; mean/std channel counts must match. For deterministic evaluation, normally do not use random augmentation transforms.

Conv2d and parameter calculation

nn.Conv2d input is (N,C_in,H,W) (or unbatched (C_in,H,W)). Weight shape is (C_out,C_in/groups,K_h,K_w). For groups=1, weights count C_out*C_in*K_h*K_w; optional bias adds C_out. With groups, input/output channels must be divisible by groups and the weight count is divided by groups. Per-axis output is floor((input+2*padding−dilation*(kernel−1)−1)/stride + 1). Pooling layers typically have no learned weights. AdaptiveAvgPool2d((1,1)) outputs one spatial average per channel regardless of input H,W; flatten from dimension 1 preserves batch.

BatchNorm2d expects channel axis C at dimension 1. With affine=True (default), it learns γ and β, two values per channel. Running mean/variance are buffers, not trainable parameters. In training it uses batch statistics and updates running estimates; in eval it uses running values when tracking is enabled. Dropout randomly zeros each element with probability p during training and scales retained elements; in eval it is identity.

Sequence modules

nn.RNN, nn.LSTM, and nn.GRU accept sequence tensors shaped (sequence,batch,features) by default; batch_first=True changes the input/output order to (batch,sequence,features), not the hidden-state order. Bidirectional modules double output feature width. LSTM returns (output,(h_n,c_n)); GRU/RNN return (output,h_n). Hidden-state shape is (num_layers*num_directions,batch,hidden_size); LSTM cell state has the same shape.

Attention and Transformer

Scaled dot-product attention uses query/key dot products divided by sqrt(d_k), softmax over keys, then a weighted sum of values. PyTorch's functional scaled attention can accept an attention mask and causal flag; mask conventions and supported kernels should be checked in the installed version docs. Transformer layers require embedding width d_model divisible by the number of heads. Sequence masks control what tokens may attend; causal masking blocks future positions in autoregressive decoding. Positional information must be supplied by the model/input embedding path if order matters.

Optimization and generation

Optimizers update the exact parameter iterable passed at construction; newly created/unregistered parameters will not update unless added. Learning rate is an optimizer setting. Gradient clipping is called after backward and before optimizer step. A GAN discriminator is commonly trained with real=1/fake=0 targets, then generator with fake=1 targets; detach fake samples during discriminator training to prevent accidental generator updates in that step. In diffusion, a common DDPM objective predicts sampled Gaussian noise with an MSE loss; reverse sampling iteratively denoises from a noise sample. Specific schedules/samplers vary by implementation.
