Week 9 · GAN and pretrained diffusion practice

GAN update order: D step uses G(z).detach() so the D loss does not update G. G step uses D(G(z)) without detaching so gradients flow back to G. Keep real-image scaling consistent with the generator output (e.g., tanh images in [−1,1]). Save fixed-seed grids; GAN losses alone can oscillate.

Pretrained text-to-image pipeline: prompt → tokenizer/text encoder → initial latent noise → repeated denoiser + scheduler steps → VAE decode → image. Seed controls repeatable randomness; prompt and negative prompt condition the generation; steps trade compute for iterative refinement.

CFG numerical: unconditional prediction 2, conditional 5, scale 3 gives 2+3(5−2)=11. It extrapolates toward prompt alignment; too much guidance may reduce diversity or quality.

LoRA

Learn low-rank updates and keep base weights. For 768×768, rank 8 adds 8(768+768)=12,288 vs 589,824 full weights = 2.08%.

Textual inversion

Learn a special token embedding to represent a concept; it does not update every model layer.

pipe = DiffusionPipeline.from_pretrained(model_id).to(device)
image = pipe(prompt, num_inference_steps=30,
             guidance_scale=6.5,
             generator=torch.Generator(device).manual_seed(7)).images[0]

Week 10 · Tokens, embeddings, attention

Tokenizer converts text to token IDs; an embedding table maps IDs to vectors. Contextual representations change as tokens exchange information. Positional information supplies order; causal masks block future keys for generation; padding masks block filler tokens.

Attention(Q,K,V)=softmax((QKᵀ)/√dk + mask)V

Hand calculation: q=[1,0], k₁=[1,0], k₂=[0,1], dk=2. Scaled scores are [.707,0]; softmax ≈ [.670,.330]. For v₁=[10,0], v₂=[0,10], output ≈ [6.70,3.30]. Softmax is over keys for each query.

Shapes: Q,K,V [B,h,T,dk]; scores and weights [B,h,T,T]; context concatenates back to [B,T,dmodel]. With B=2,T=5,h=4,dk=16: scores [2,4,5,5]. Dense attention scales quadratically with T.

scores = (q @ k.transpose(-2, -1)) / (d_k ** 0.5)
scores = scores.masked_fill(mask, float("-inf"))
weights = scores.softmax(dim=-1)  # normalize across keys
context = weights @ v
Exam traps: scale before softmax; normalize across key positions; causal mask removes future positions; concatenate heads along feature dimension; attention alone needs position clues.

Week 11 · BERT, GPT, translation, PEFT

ArchitectureAttention / objectiveTypical use
Encoder-only (BERT-like)Bidirectional input context; masked-token pretrainingClassification, tagging, retrieval embeddings
Decoder-only (GPT-like)Causal mask; next-token predictionText generation
Encoder-decoderBidirectional encoder + causal decoder cross-attending to sourceTranslation, conditional generation

Teacher forcing shifts target: input [BOS, y₁, y₂] predicts [y₁, y₂, EOS]. At inference, use generated prior tokens; this train/test mismatch can cause exposure bias. Translation metrics such as BLEU compare overlap and do not fully measure meaning.

LoRA: for W∈ℝout×in, approximate update ΔW=BA with rank r; trainable count is r(out+in) instead of out×in. For 1024×1024 rank 4: 8,192 adapter parameters vs 1,048,576 full parameters = 0.78125%.

Prompt budget example: context 4,096; instructions 300; user 150; examples 900; evidence 1,800; reserve 100 → generation budget 4096−300−150−900−1800−100=846 tokens.

RAG and evaluation

Pipeline: chunk/index trusted documents → retrieve relevant chunks → assemble evidence prompt → generate → validate support and output format. Search errors (missing evidence) differ from answer errors (evidence present but misused). RAG does not guarantee factual answers.

Top-5 contains 3 relevant chunks; corpus has 6 relevant chunks. Precision@5=3/5=.60; recall@5=3/6=.50. If the first relevant result is at rank 4, reciprocal rank is 1/4=.25. MRR averages reciprocal rank across questions.

Safety/reliability: retrieved documents are evidence, not higher-priority instructions. Validate structured output syntax separately from factuality, evidence support, authorization, and safe actions.

End-of-pack code skeleton: retrieve then answer

from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.metrics.pairwise import cosine_similarity

documents = ["... trusted course notes ...", "... another passage ..."]
vectorizer = TfidfVectorizer(stop_words="english")
doc_vectors = vectorizer.fit_transform(documents)

def retrieve(question, k=3):
    q = vectorizer.transform([question])
    scores = cosine_similarity(q, doc_vectors)[0]
    ids = scores.argsort()[::-1][:k]
    return [(documents[i], float(scores[i])) for i in ids]

def make_prompt(question):
    hits = retrieve(question)
    evidence = "\n".join(text for text, score in hits)
    return ("Answer only from the evidence. If it is insufficient, say so.\n"
            f"Evidence:\n{evidence}\nQuestion: {question}\nAnswer:")

prompt = make_prompt("What does the course say about attention?")
# Send prompt to the chosen LLM, then validate citations and answer support.

Exam-ready distinction: retrieval supplies external text; generation writes an answer. Measure retrieval coverage and answer faithfulness separately.
