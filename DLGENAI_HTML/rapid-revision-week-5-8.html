Week 5 · Sequence models: RNN, BPTT, LSTM

A sequence has meaningful order. An RNN uses one shared transition at each time step: ht=φ(Wxxt+Whht−1+b). Many-to-one predicts one label from the final/pooled state; many-to-many predicts at multiple positions.

Backpropagation through time unrolls the recurrent computation. Long products of derivatives can vanish (learning signal shrinks) or explode (signal grows); gradient clipping limits an excessive norm. LSTM gates control memory using ct=ft⊙ct−1+it⊙gt and ht=ot⊙tanh(ct).

Shape check: for input [B,T,D], hidden size H, unidirectional LSTM output is [B,T,H] and final hidden has [layers,B,H] unless batch-first only changes the input/output layout.

Week 6 · Sequential-data practice

Text tasks

Token IDs → embedding vectors → sequence model → task head. Pad sequences for batching, but pass true lengths or masks so padding does not affect the state or loss. For sentiment, use a many-to-one head. For language modeling, shift by one token: input [BOS, I, like], targets [I, like, cats].

Teacher forcing: training uses the correct previous token; generation must use the model’s previous guess. That difference can cause exposure bias. Perplexity is exp(mean token NLL). If mean NLL is 0.7, perplexity e0.7≈2.01.

# next-token pairs: same sentence, shifted by one position
inputs = token_ids[:, :-1]
targets = token_ids[:, 1:]
logits = model(inputs)  # [B,T-1,V]
loss = cross_entropy(logits.reshape(-1, V),
                     targets.reshape(-1), ignore_index=PAD_ID)

Time-series forecasting

With N=12 ordered values, lookback L=3, horizon H=1, number of windows is N−L−H+1=9. Split chronologically. Fit scalers on training period only; never let future values influence training inputs or preprocessing. For predictions [2,4] vs targets [3,2], MAE =(1+2)/2=1.5; RMSE =√((1²+2²)/2)=√2.5≈1.58.

Week 7 · Autoencoders, VAEs, GANs

Autoencoder and VAE

An autoencoder encodes input to a bottleneck and decodes a reconstruction. A VAE learns a distribution over latent codes and balances reconstruction quality with a KL penalty that keeps latent codes close to a sampleable prior:

LVAE = Lreconstruction + β·DKL(q(z|x) ∥ p(z))
z = μ + σ⊙ε,   ε∼N(0,I)

For one Gaussian latent dimension with μ=1, σ²=4, KL to a standard normal is ½(μ²+σ²−1−lnσ²)=½(1+4−1−ln4)≈1.307. Reparameterization isolates randomness in ε so gradients can update μ and σ.

GAN

Generator creates fakes; discriminator learns real vs fake. Discriminator step uses real→1 and detached fake→0. Generator step labels generated samples as real and must keep the gradient path through the discriminator to the generator. At ideal equilibrium the discriminator is uncertain, D(x)≈0.5. Mode collapse means diverse noise inputs produce only a few similar outputs.

For real score 0.8 and fake score 0.2, discriminator BCE terms are −ln(0.8)≈0.223 each; if summed, total 0.446. Generator non-saturating loss on fake score .2 is −ln(.2)≈1.609.

# D step: stop generator gradients
loss_D = bce(D(real), ones) + bce(D(G(z).detach()), zeros)
loss_D.backward(); opt_D.step()
# G step: keep gradient path through D to G
loss_G = bce(D(G(z)), ones)
loss_G.backward(); opt_G.step()
Metric caveat: FID compares feature distributions of real and generated sets; lower is often better, but sample count and preprocessing matter. A single metric cannot replace visual inspection/diversity checks.

Week 8 · Diffusion models

Forward diffusion gradually adds Gaussian noise. The closed-form noisy sample at time t is:

xt = √ᾱtx0 + √(1−ᾱt)ε,   ε∼N(0,I)
αt=1−βt,   ᾱt=∏s=1tαs

Numerical: if ᾱt=0.64, x₀=2, ε=−1, then xt=0.8(2)+0.6(−1)=1.0. The denoiser is trained to predict ε, commonly with MSE ||ε−εθ(xt,t)||². In generation, start with noise and repeatedly remove predicted noise using a scheduler.

DDPM uses a stochastic reverse process; DDIM can use a shorter, often deterministic path. Latent diffusion denoises a compressed representation, then a decoder turns it into pixels. Classifier-free guidance combines unconditional and prompt-conditioned noise predictions:

εguided=εuncond+w(εcond−εuncond)
2 + 3(5−2) = 11

Guidance can extrapolate beyond the conditional prediction; high scale can overconstrain samples.

eps = model(x_t, t, condition)
x_prev = scheduler.step(eps, t, x_t).prev_sample

End-of-pack code skeleton: LSTM sequence classifier

import torch
from torch import nn

class SentimentLSTM(nn.Module):
    def __init__(self, vocab_size, emb_dim=64, hidden=96):
        super().__init__()
        self.embedding = nn.Embedding(vocab_size, emb_dim, padding_idx=0)
        self.rnn = nn.LSTM(emb_dim, hidden, batch_first=True)
        self.head = nn.Linear(hidden, 1)
    def forward(self, ids, lengths):
        x = self.embedding(ids)          # [B,T,E]
        packed = nn.utils.rnn.pack_padded_sequence(
            x, lengths.cpu(), batch_first=True, enforce_sorted=False)
        _, (h_n, _) = self.rnn(packed)
        return self.head(h_n[-1])        # [B,1] logit

model = SentimentLSTM(vocab_size=5000)
loss_fn = nn.BCEWithLogitsLoss()
optimizer = torch.optim.Adam(model.parameters(), lr=1e-3)
for ids, lengths, label in loader:
    optimizer.zero_grad(set_to_none=True)
    logits = model(ids, lengths)
    loss = loss_fn(logits, label.float().unsqueeze(1))
    loss.backward()
    nn.utils.clip_grad_norm_(model.parameters(), 1.0)
    optimizer.step()

What to say in an exam: embeddings map IDs to vectors; packed sequences skip padding; final hidden state is the sequence summary; logits go into BCE-with-logits; clipping limits exploding gradients.
