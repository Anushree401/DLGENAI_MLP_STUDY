1. GAN practice: train, monitor, and sample

1.1 The loop as a two-player optimization problem

Given real minibatch x and noise z, the generator produces x̃=G(z). A discriminator returns a realness logit. The discriminator update teaches real→1 and generated→0; the generator update teaches generated→1. It is not one ordinary supervised classifier: each network’s objective changes as the other changes.

  1. Prepare real: use a consistent image shape and normalize to match generator output. If G ends in tanh, train on [−1,1].
  2. Update D: clear D gradients; evaluate D(x) and D(G(z).detach()); compute real/fake losses; backpropagate and step D.
  3. Update G: clear G gradients; sample z and compute D(G(z)); label fake as real; backpropagate through D to G; step G.
  4. Monitor: save generated grids from a fixed z batch each epoch; inspect diversity, artifacts, and memorization as well as losses.
LD=BCE(D(x),1)+BCE(D(G(z).detach()),0)
LG=BCE(D(G(z)),1) (non-saturating form)

Use logits with BCEWithLogitsLoss; it combines sigmoid and BCE stably. D receives logits, not sigmoid probabilities. The output of D for each image is typically [B,1]. The real/fake labels should have the same shape.

1.2 Why detach fake only for the D update?

In the D step, the optimization target is D’s parameters; fake.detach() blocks gradients from this discriminator loss into G. In the G step, fake must remain connected to G. Gradients travel through D’s computation to its input and then into G; D’s parameters can be frozen to avoid calculating their gradients while retaining this input gradient.

# D phase
opt_D.zero_grad(set_to_none=True)
loss_D = bce(D(real), ones) + bce(D(G(z).detach()), zeros)
loss_D.backward()
opt_D.step()

# G phase: freeze D weights, but do NOT detach G(z)
for p in D.parameters(): p.requires_grad_(False)
opt_G.zero_grad(set_to_none=True)
loss_G = bce(D(G(z)), ones)
loss_G.backward()
opt_G.step()
for p in D.parameters(): p.requires_grad_(True)

1.3 Architecture and image normalization

A DCGAN commonly maps a latent vector [B,Z,1,1] through transposed convolutions to an image, and maps the image back to a scalar score through strided convolutions. Spatial dimensions follow the convolution formula; design the generator/discriminator so output images exactly match training image size. When G outputs tanh in [−1,1], transform ToTensor pixels x∈[0,1] to 2x−1. Mismatched scales make the discriminator’s job artificially easy.

1.4 Losses do not tell the whole story

GAN losses can oscillate and need not decrease monotonically as samples improve. Compare fixed-seed sample grids over time. Mode collapse appears when many noise inputs yield a small set of similar outputs. FID estimates feature-distribution distance using real and generated sample sets; it needs enough samples and can be biased by preprocessing. Precision/recall style metrics separate fidelity and coverage. Human review remains useful for prompt/data-specific defects; no single score captures all quality.

2. Pretrained diffusion: from prompt to image

2.1 What a text-to-image pipeline loads

A Stable-Diffusion-style pipeline generally packages a tokenizer and text encoder, denoiser (often a U-Net in classic latent diffusion), a VAE encoder/decoder, and a scheduler. At inference, tokenize the prompt, encode it, start from random latent noise, repeatedly predict noise (conditioned on the text), update the latent according to scheduler timesteps, and decode the final latent to pixels. Text guidance may use unconditional and conditional estimates.

prompt → token IDs → text embeddings → guided denoise loop → latent z₀ → VAE decoder → image

Classic latent diffusion shrinks images in the VAE latent, so denoising costs less than operating on every pixel. The exact latent scale, channel count, scheduler, and model architecture depend on the checkpoint; do not memorize one model’s numbers as universal.

2.3 Classifier-free guidance numeric

Given unconditional noise prediction εu=2, conditional prediction εc=5, and guidance w=3:

εguided=εu+w(εc−εu)=2+3(5−2)=11

The result extrapolates beyond εc; it is not a convex average when w>1. At w=0, the unconditional result remains; w=1 returns εc. High guidance is not always “better.”

2.4 Prompt composition and controlled iteration

Describe subject, action, setting, composition, visual medium, lighting, and constraints when they matter. Avoid contradictory descriptors. Change one factor per experiment, keep the seed and other settings fixed, and save a contact sheet. A prompt is conditioning, not a guarantee: models may miscount objects, misspell text, or combine incompatible attributes.

from diffusers import DiffusionPipeline
import torch

device = "cuda" if torch.cuda.is_available() else "cpu"
dtype = torch.float16 if device == "cuda" else torch.float32
pipe = DiffusionPipeline.from_pretrained(
    MODEL_ID, torch_dtype=dtype, use_safetensors=True
).to(device)
gen = torch.Generator(device=device).manual_seed(1234)
image = pipe(
    prompt="a watercolor diagram of a neuron, clean labels, white background",
    negative_prompt="blurry, cluttered, illegible text",
    num_inference_steps=30, guidance_scale=6.5, generator=gen
).images[0]
image.save("sample.png")

3. Personalization: full tuning, LoRA, textual inversion

3.1 What is adapted?

  • Full fine-tuning / DreamBooth-style adaptation: update many or all model weights using examples of a subject/style. Flexible but costly, and small datasets can overfit.
  • LoRA: freeze original matrix W; learn low-rank factors A and B so W′=W+(α/r)BA. Store a compact adapter and load it alongside the base.
  • Textual inversion: learn a new embedding for a placeholder token while keeping the larger model mostly fixed.
  • Control adapters: condition on structural inputs such as edges, depth, or pose; the task plan should identify the control model and compatible base pipeline.

For a linear projection din→dout, full matrix parameters=dindout; rank-r LoRA adds r(din+dout) parameters (ignoring bias). For 768→768 and r=8, full=589,824; LoRA=8(768+768)=12,288, which is 2.083% of the dense matrix. Adapter parameter ratio is not the same as total-model ratio.

3.2 Load an image-generation LoRA

# After loading a compatible Diffusers pipeline:
pipe.load_lora_weights("your-account/your-style-adapter",
                       adapter_name="style")
image = pipe("a small cabin in the learned watercolor style").images[0]
# To return to the base model in supported pipelines:
pipe.unload_lora_weights()

Adapters are checkpoint-specific: the compatible base model, target modules, text encoder(s), and scale matter. Keep the adapter configuration with its weights and verify prompt behavior on held-out prompts.

4. Worked numericals and exam-style code reading

Numerical A: one GAN batch loss

For D(real)=.8 and D(fake)=.2, the per-example BCE losses are −ln(.8)=.2231 and −ln(1−.2)=.2231. If summed, LD=.4462; if averaged over the two examples, LD=.2231. With non-saturating G, LG=−ln(.2)=1.609. The reduction convention changes the displayed magnitude.

Numerical B: CFG interpolation/extrapolation

εu=[1,0], εc=[3,2], w=2: εg=[1,0]+2([3,2]−[1,0])=[1,0]+[4,4]=[5,4].

Numerical C: LoRA savings for one adapted layer

For 1024×1024 projection and r=4: dense=1,048,576 parameters; LoRA=4(1024+1024)=8,192, about 0.78125% of that matrix. This excludes scaling, optional biases, and any unfreezed modules.

5. Exam-style practice with worked answers

Q1. In discriminator training, should G(z) remain connected to G?

No. Detach fake data for the discriminator update so that the D loss updates D only. In the generator update, keep G(z) connected so gradients reach G.

Q2. If εu=1, εc=3, and w=2, what is εguided?

1+2(3−1)=5.

Q3. Does a guidance scale of 3 mean “three times the conditional prediction”?

No. It is εu+3(εc−εu). It starts from unconditional prediction and scales the difference vector.

Q4. G ends with Tanh, while real images remain ToTensor values in [0,1]. What mismatch exists?

The two distributions occupy different numeric ranges. Normalize the real images to [−1,1], or choose a matching generator output activation/data scale.

Q5. A 768×768 matrix gets rank-8 LoRA. How many trainable low-rank parameters are added?

8(768+768)=12,288, excluding any biases or additional trainable modules.

Q6. A fixed seed improves which property?

Reproducibility/control of the initial random noise for comparisons. It does not guarantee higher quality or identical results across every device/backend/version.

6. Complete end-of-week lab: train a GAN and use pretrained diffusion

This end-to-end script has two independent tracks: a small DCGAN learns MNIST digits from scratch; a pretrained text-to-image pipeline generates an image from a prompt. It saves a fixed-noise grid and a diffusion image. Model download, checkpoint license, GPU memory, and training time depend on your environment.

"""Week 9 lab: DCGAN training + pretrained diffusion inference."""
import os
import torch
from torch import nn
from torch.nn import functional as F
from torch.utils.data import DataLoader
from torchvision import datasets, transforms, utils

SEED = 29
torch.manual_seed(SEED)
device = torch.device("cuda" if torch.cuda.is_available() else "cpu")

# --------------------- Part A: train DCGAN -------------------
BATCH, ZDIM, EPOCHS = 128, 100, 5
train_data = datasets.MNIST(
    root="data", train=True, download=True,
    transform=transforms.Compose([
        transforms.ToTensor(),
        transforms.Normalize((0.5,), (0.5,))  # [0,1] -> [-1,1]
    ])
)
loader = DataLoader(train_data, batch_size=BATCH, shuffle=True,
                    drop_last=True, num_workers=0)

class Generator(nn.Module):
    def __init__(self, zdim=100):
        super().__init__()
        self.net = nn.Sequential(
            nn.ConvTranspose2d(zdim, 128, 7, 1, 0, bias=False),
            nn.BatchNorm2d(128), nn.ReLU(True),       # 1 -> 7
            nn.ConvTranspose2d(128, 64, 4, 2, 1, bias=False),
            nn.BatchNorm2d(64), nn.ReLU(True),        # 7 -> 14
            nn.ConvTranspose2d(64, 1, 4, 2, 1),
            nn.Tanh()                                  # 14 -> 28
        )
    def forward(self, z):
        return self.net(z)

class Discriminator(nn.Module):
    def __init__(self):
        super().__init__()
        self.net = nn.Sequential(
            nn.Conv2d(1, 64, 4, 2, 1), nn.LeakyReLU(0.2, True),
            nn.Conv2d(64, 128, 4, 2, 1, bias=False),
            nn.BatchNorm2d(128), nn.LeakyReLU(0.2, True),
            nn.Flatten(), nn.Linear(128 * 7 * 7, 1)  # one logit/image
        )
    def forward(self, x):
        return self.net(x)

G = Generator(ZDIM).to(device)
D = Discriminator().to(device)
opt_G = torch.optim.Adam(G.parameters(), lr=2e-4, betas=(0.5, 0.999))
opt_D = torch.optim.Adam(D.parameters(), lr=2e-4, betas=(0.5, 0.999))
bce = nn.BCEWithLogitsLoss()
fixed_z = torch.randn(64, ZDIM, 1, 1, device=device)
os.makedirs("week9_samples", exist_ok=True)

for epoch in range(EPOCHS):
    G.train(); D.train()
    d_running = g_running = 0.0
    for real, _ in loader:
        real = real.to(device)
        b = real.size(0)
        ones = torch.ones(b, 1, device=device)
        zeros = torch.zeros(b, 1, device=device)

        # Update D: real -> 1, fake -> 0; stop fake loss at G.
        opt_D.zero_grad(set_to_none=True)
        z = torch.randn(b, ZDIM, 1, 1, device=device)
        fake = G(z)
        d_real = bce(D(real), ones)
        d_fake = bce(D(fake.detach()), zeros)
        loss_D = d_real + d_fake
        loss_D.backward()
        opt_D.step()

        # Update G: fool D; preserve the graph from D(fake) back into G.
        for p in D.parameters(): p.requires_grad_(False)
        opt_G.zero_grad(set_to_none=True)
        z = torch.randn(b, ZDIM, 1, 1, device=device)
        generated = G(z)
        loss_G = bce(D(generated), ones)
        loss_G.backward()
        opt_G.step()
        for p in D.parameters(): p.requires_grad_(True)
        d_running += loss_D.item(); g_running += loss_G.item()

    G.eval()
    with torch.no_grad():
        grid = G(fixed_z).cpu()                # [64,1,28,28], [-1,1]
        utils.save_image(grid, f"week9_samples/epoch_{epoch+1:02d}.png",
                         normalize=True, nrow=8)
    print(f"epoch {epoch+1}: D={d_running/len(loader):.3f}, "
          f"G={g_running/len(loader):.3f}")

os.makedirs("week9_samples", exist_ok=True)
torch.save({"G": G.state_dict(), "D": D.state_dict()},
           "week9_samples/dcgan_mnist.pt")

# ---------------- Part B: pretrained diffusion ---------------
# Install a compatible diffusers/transformers/accelerate/safetensors stack.
# Some model repos require a license agreement and Hugging Face login.
from diffusers import DiffusionPipeline

model_id = "stable-diffusion-v1-5/stable-diffusion-v1-5"  # choose an accessible checkpoint
dtype = torch.float16 if device.type == "cuda" else torch.float32
pipe = DiffusionPipeline.from_pretrained(
    model_id, torch_dtype=dtype, use_safetensors=True
).to(device)

prompt = "an educational watercolor illustration of a tiny robot reading a book, " \
         "centered composition, warm daylight, simple clean background"
negative = "blurry, cluttered, low contrast, text, watermark"
generator = torch.Generator(device=device).manual_seed(SEED)
result = pipe(
    prompt=prompt,
    negative_prompt=negative,
    num_inference_steps=30,
    guidance_scale=6.5,
    generator=generator,
    num_images_per_prompt=1
)
result.images[0].save("week9_samples/pretrained_diffusion.png")
print("Saved GAN grids/checkpoint and pretrained diffusion sample.")

Code walkthrough and shape audit

  1. Real-data scaling: MNIST ToTensor creates [0,1]; Normalize(.5,.5) changes it to [−1,1], matching G’s tanh.
  2. Generator shapes: [B,100,1,1]→[B,128,7,7]→[B,64,14,14]→[B,1,28,28].
  3. Discriminator: image [B,1,28,28]→[B,64,14,14]→[B,128,7,7]→[B,1] logit.
  4. Alternating updates: fake is detached only for D training; D weights are frozen during G step while gradients can pass back to G.
  5. Fixed grid: reusing fixed_z makes epoch-to-epoch visual comparisons meaningful.
  6. Pretrained pipeline: model, text encoder, VAE, scheduler are loaded from the checkpoint; each call runs multiple denoising steps.
  7. Reproducibility: fixed seed, prompt, checkpoint and settings make comparisons controlled, but backends may not guarantee exact bitwise equality.
  8. Security: authenticate with the CLI or environment-managed credentials; never paste tokens into the notebook or public source.
Compute and rights: this script downloads MNIST and a pretrained checkpoint. Diffusion inference is memory-intensive; use a compatible smaller model or CPU offload when necessary. Read the checkpoint model card/license and respect image/data rights.

7. Week 9 formula card and sources

GAN update

D learns real=1/fake=0; non-saturating G learns fake=1.

Guidance

εg=εu+w(εc−εu).

LoRA
